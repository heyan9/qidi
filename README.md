# 奇的放大镜
用法1. 在 GitHub 新建仓库，把本目录全部文件上传（含 .github 文件夹）。
2. 仓库 Actions → Build APK → 运行完成后在 Artifacts 下载 apk，装到手机。
3. 打开App → 开启悬浮窗（授权“显示在其他应用上层”）。
4. 数据同步用另一个仓库最好：新建 qidi-data 仓库，建 fine-grained token（仅该仓库 Contents: Read and write），填进App。


功能
奇的放大镜

一个装在手机悬浮窗里的"点赞判断训练助手"：边看内容边判断，边复盘边成长。

一句话介绍

奇的放大镜是一个常驻屏幕的悬浮小圆标。看内容时点一下就能记录判断结果，自动统计胜率、归纳关键词，并把所有数据同步到你自己的 GitHub，换手机、重装也不丢。

核心功能

🔍 悬浮窗，随时可用

一个小圆标浮在任何应用上，可以拖动，透明度可调。
圆标像电量一样显示今日准确率，里面显示百分比，下方小字显示"对/已做"，比如 2/5。
点圆标展开选项面板，面板紧跟在圆标下方，黑底简洁。

⬛ 黑色遮挡

先把内容遮住，凭第一直觉判断，防止被答案影响。
遮挡可以拖动、缩放、关闭，位置和大小会记住。
选完区间后遮挡自动打开，判断完对错后自动重新盖上。

🎯 快速记录

一键选择区间：1、2、3、4、5、5-8、8-1k、1k+、2k+。
点"对"或"错"后，依次选择内容类型、正向关键词、反向关键词。
关键词支持随时临时添加，自动保存并选中，所有选项都能自己修改。

📊 数据洞察

主页显示近 7 日平均胜率。
高频关键词统计，显示每个词出现的次数和对应的正确率，帮你发现哪些特征和高胜率挂钩。
每日手动打分 1-10。近 15 日均分低于 5 时，App 会提醒"内容创意存在严重不足，需要提高胜率以及内容敏感度"。
准确率排行榜，按日期排名。

📝 错题记事本

悬浮窗里的黑底记事本，可拖动、缩放、调透明度，随手记录出错原因。
主页也能查看和修改所有笔记。

☁️ GitHub 云同步

胜率、排行榜、关键词、笔记、评分、自定义选项自动同步。
打开 App 时自动同步，并会先从云端恢复本地缺失的数据。
数据以文件形式存在你自己的仓库里，随时可查看，完全由你掌控。
设计风格

白底加知乎蓝，半透明毛玻璃质感卡片，悬浮窗统一黑底。图标是黑色渐变底加银白放大镜。

适合谁
想训练内容判断力、提高"内容敏感度"的创作者和运营者。
喜欢用数据复盘、追踪自己进步的人。
想要一个轻量、不打扰、数据自己掌控的小工具的人。
